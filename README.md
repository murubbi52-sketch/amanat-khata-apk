# আমানত খাতা — Amanat Khata (APK Releases)

This repository hosts **only the official APK release files** of the Amanat Khata app (ধার-দেনার হিসাব রাখার অ্যাপ). No source code lives here — the source repository is private.

## Download
Get the latest APK from the **Releases** section of this repository. The app also downloads its updates from here, inside the app itself.

## Verify your download
- Package name: `app.hawlatkhata`
- Every release lists the SHA-256 of its APK file in the release notes, and the same hash is published in the app's update manifest (`app-version.json`). The app itself verifies the signing certificate of a downloaded update before offering to install it.
